**Energie Dashboard Application** is a web-based dashboard that visualizes electricity generation data across Europe. The application provides an interactive, centralized view of key energy metrics, including energy prices, electricity flow between countries, and types of electricity generation.

### Tech Stack
- **Data:** Energy Charts API
- **Frontend:** Bootstrap, Highcharts
- **Infrastructure & Deployment:** Docker, Node.js
