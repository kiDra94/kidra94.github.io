**Today I Learned (TIL)** is a lightweight digital diary designed for developers and lifelong learners to track their daily progress. Instead of losing track of small coding tips, tutorials, or new concepts, this application provides a centralized and organized space to document them.

### Key Features
- **Daily Logs:** Easily add short notes and code snippets about what you learned on any specific day.
- **Subject Organization:** Categorize your learnings by subjects or technologies to keep everything structured.
- **Calendar View:** Get a clear, visual overview of your learning streak and past entries using a clean calendar interface powered by Day.js.
- **Fast & Responsive:** Built with Vite and Vue 3 for a lightning-fast and seamless user experience.

### Tech Stack
- **Frontend Framework:** Vue 3
- **Build Tool:** Vite
- **Date Management:** Day.js
- **Infrastructure:** Docker (Containerization for easy deployment)
