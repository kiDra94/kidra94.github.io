**Corporate Network – YUPP Software Entwicklung GmbH**  
A collaborative project focused on the complete planning, documentation, and simulation of a corporate network architecture. 

### Key Features & Configurations
- **Topology & IP Management:** Designing the network topology and creating a comprehensive IP schema using VLSM.
- **Routing & Switching:** Configuring routers and switches, defining VLAN schemas, and setting up NAT/PAT on the border router.
- **Security & IoT:** Implementing LAN security protocols and configuring an IoT server with restricted access policies.

### Tech Stack
- **Simulation Tool:** Cisco Packet Tracer
- **Core Concepts:** Network Architecture, VLSM, VLAN, Subnetting, Security
