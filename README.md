# Personal Portfolio

My personal portfolio website, built to showcase my projects, skills, and background as a Junior Software Developer. 

**Live Website:** [drazen.plavsic.com](https://kiDra94.github.io)

## 🛠️ Tech Stack

This project is designed with a focus on minimalism, speed, and clean code.

* **Framework:** [Astro](https://astro.build/) (Static Site Generation)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Deployment:** GitHub Actions & GitHub Pages
