# Personal Portfolio

My personal portfolio website, built to showcase my projects, skills, and background as a Junior Software Developer. 

**Live Website:** [drazenplavsic.dev](https://www.drazenplavsic.dev)

## 🛠️ Tech Stack

This project is designed with a focus on minimalism, speed, and clean code.

* **Framework:** [Astro](https://astro.build/) (Static Site Generation)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Deployment:** FTP upload to Infomaniak with `npm run deploy`; GitHub Actions additionally publishes every push to `main` on GitHub Pages
